# FT8 网页

`tools/ft8log_http.py`，用户服务 `influ-ft8log`，端口 8073，局域网可访问。页面上有：一键 CQ、手动发送、待批准的回复、收发记录、ADIF 下载（`/qsos.adi`）、收发全文（`/events`），以及今天的收听时机。

## 登录

不设登录时，局域网里谁都能让手台发射。

在站上运行 `python3 tools/ft8log_http.py passwd`（`--user` 指定登录名，默认 `ft8`）设登录：

- 按提示输入口令，口令以 PBKDF2 散列存进 `~/influ/private/ft8web.auth`，权限 600。
- 从下一个请求起，所有页面都要 HTTP Basic 登录；浏览器问一次就会记住。
- 删掉这个文件即取消登录。

页面是明文 HTTP：登录挡得住局域网里的其他人，挡不住窃听。

## 自动与手动

- 只打开或查看页面，什么都不改变，站点照常全自动。
- 一键 CQ 保持或恢复全自动。CQ 发出后，调度器在对应时隙为可能的回应开接收窗口（四分钟的通联优先期），之后的通联自动进行；V4 仍由 sdrmux 统一切换。
- 手动输入后点“发送”进入手动会话：之后状态机和 LLM 的回复都显示为待批准，点“批准并发送”才发一帧。批准只对当前这条回复有效，回复一变或发完即失效。
- 手动自由文本不超过 13 个 ASCII 字符；标准 FT8 消息必须用本台呼号。
- 关闭或离开页面会立即结束手动会话；断网、浏览器崩溃或网页服务停止时，最长约 6 秒后恢复全自动。
- 已开始的帧不能中途取消，约 13 秒后结束。还没开始的手动发送随页面关闭取消；一键 CQ 的自动任务继续。
- 别的页面只能看，不能接管、批准或关闭当前的手动会话。

## 收听时机

页面把今天按半小时画成一行：

- 颜色越深，到达风险模型预计那一小时来的飞机越多。
- 红色是训练模型保护的时段。
- 框住的是现在。

下面一行写今天已切出的秒数、本小时的窗口数，以及调度器最近一次判定的结论和原因。

## 其他

- 手动发送和自动发送走同一个调度器、同一个校准过的发送程序。网页本身不碰串口，也没有数据库或前端框架。
- 自由文本不带发送者呼号，回应按最近一次通联的音频频率和时隙判断归属；直接手动发自由文本时，在本台实测音频频率附近找回应。频点拥挤时可能认错对方。
